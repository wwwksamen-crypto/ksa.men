# KSA.MEN

منصة هوية وحضور مهني سعودية، مصممة أولًا للجوال، مع مواقع شخصية على نطاقات حقيقية، محرر ومراجعات ونسخ منشورة مستقلة، ملفات PDF/ATS عربية وإنجليزية، بطاقات وQR وvCard، محافظ نقاط وإحالات واستحقاقات، مراسلة مؤقتة، رادار RSS/Atom، وإدارة متعددة الأدوار.

**الإنتاج:** https://ksa.men — يبقى إعداد قفل المالك كما هو. **الإدارة:** https://ksa.men/admin.

## البنية

React وTypeScript وVite للواجهة، Hono وCloudflare Workers للخادم، D1 للبيانات والمعاملات، R2 خاص للوسائط والنسخ المشفرة، Workers AI للترجمة الفعلية، وResend للبريد. لا تعتمد الخدمة على استضافة Manus. موارد التطبيق مرتبطة في `wrangler.jsonc`.

## التطوير والنشر

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm run deploy
```

توضع أسرار التطوير في `.dev.vars` المستثنى من Git، وأسرار التشغيل في Workers Secrets. لا تضف رمز نشر Cloudflare أو مفاتيح الجلسات أو النسخ أو المستخدمين إلى المستودع.

## المصادر والاستنساخ

```bash
python3 scripts/package_transfer.py source.zip
python3 scripts/package_transfer.py clone.zip --clone --domain your-domain.example --owner-email owner@example.com --brand 'Your Brand'
```

حزمة الاستنساخ لا تنقل قاعدة المستخدمين أو الأسرار أو وثائق الشركة أو حسابها البنكي أو معرفات موارد الإنتاج. يجب تزويدها بموارد صاحبها وهوية صاحبها وأسراره، وتبقى الحوالات معطلة إلى أن تُضبط بيانات رسمية. لا تطبق ترحيلات الاستنساخ المعدلة على قاعدة الأصل.
