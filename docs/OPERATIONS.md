# تشغيل KSA.MEN واستعادته

بطاقة محدثة في 18 نوفمبر 2026 ضمن المواءمة الانتقائية. المنتج الحالي مستقل على Cloudflare Workers وD1 وR2 وWorkers AI وResend، والمستودع `wwwksamen-crypto/ksa.men`. لا تغيير استضافة أو هوية أو موارد إنتاج لمجرد تحديث هذه الوثيقة.

## المسؤولية وحدود التفعيل

الجهة المالكة شركة رجال الوطن القابضة. اعتماد سياسة الاحتفاظ ومسؤول التشغيل والحوادث وبديله وأهداف التعافي يبقى قراراً مؤسسياً، ولا تتولى الشيفرة اختيارهم. انظر `retention-alignment-20261118.md` للفئات والوضع التقني والقرارات غير المحسومة. هدفا RPO24ساعة وRTO4ساعات اقتراحان لا ضمانان مثبتان؛ تبقى الاستعادة والإتلاف الجديد وراء بوابتي اعتماد السياسة ونجاح التمرين والتفويض المحدد.

## الدخول والإدارة

مسار الإدارة `/admin` ومسار العضو `/start` أو `/login` مع مسار المصادقة القائم `/auth`. الرمز صالح لعشر دقائق ولمرة واحدة، والرمز والجهاز والجلسة لا تسلم في تقارير أو Git. البريد العام للرمز من مرسل المنصة المؤسسي؛ لا تغير OWNER_EMAIL التاريخي أو أسرار البريد أثناء المواءمة.

PIN مع البريد والجهاز الموثوق يبقى المسار السريع، لكنه لا يمنح تحققاً حديثاً. العمليات الحساسة القائمة والعمليات الجديدة للحذف النهائي وتصدير التدقيق تحتاج تحقق بريد خلال 15 دقيقة، ويعيد الخادم `REAUTH_REQUIRED` مع الرسالة القديمة المتوافقة. تستخدم الواجهة نافذة إعادة التحقق الموجودة ولا تنفذ حذفاً تلقائياً بعد إغلاقها. فتح السجل وأثر الحذف والتحرير والاعتماد المعتاد لا تحتاج تحققاً إضافياً. سبب الحذف واختيار نطاقه يبقيان في المكون ما دام هدفه ثابتاً.

التغيير الفعلي للدور أو التفويض المالي أو حالة الحساب يسحب جلسات وأجهزة الحساب المتأثر فقط في دفعة D1 ذرية. إعادة إرسال الدور/المال/الحالة نفسها لا تسحب الدخول. إعادة تفعيل الحساب لا تعيد ثقة جلساته وأجهزته القديمة. التغيير المتزامن لا يكتب فوق صلاحية أحدث، وفشل الدفعة يعيد الحساب والجلسات والأجهزة معاً. لا يعيد تراجع Worker صلاحية جلسة سحبت.

القفل وDNS والأسرار والأرصدة تبقى كما وجدناها، ولا يفتحها نشر أو مهاجرة. صلاحيات الخادم لا تعتمد على زر مخفي أو متصفح وحده.

## المصدر والفحص والنشر

تستعمل الاعتمادات والقفل والأوامر القائمة، دون توسيعها:

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm exec wrangler deploy --dry-run
```

اختبارات هذه المرحلة على SQLite ووسائط مصطنعة، لا على D1/R2 الإنتاج. لا جولات متصفح مرحلية متكررة، ولا إرسال بريد اختبار إلى أعضاء أو إتلاف بياناتهم. تُقرأ نتائج الملفات المحلية كما هي؛ لا يحمل نجاح اختبار سابق معنى نجاح الإصدار الحالي.

قبل التطبيق الإنتاجي يُراجع origin/main وأي تحرير بشري أحدث، وتؤخذ CP2 محدثة بعد تفويض الإصدار المقصود. تُحفظ نقطة المصدر عند كل انتقال. لا force-push ولا تعديل مهاجرة مطبقة؛ تضاف مخططات توافقية ثم خادم يقبل العملاء القديمين ثم واجهة. لا يفعّل مخطط إضافي إتلافاً جديداً تلقائياً.

موارد التطبيق معرفة في `wrangler.jsonc`. رمز Cloudflare في البيئة خارج المستودع ومقيد بالحساب، ويُتحقق من صلاحيته واستبعاد Billing وتاريخ انتهائه قبل النشر. لا يكتب في رسائل أو ملفات عامة. النشر والموارد الجديدة لا يبدأان من تحديث هذه الوثيقة؛ يتبعان التفويض والنطاق المتفق عليهما.

## النسخ الحالية ونقاط الرجوع

Cron القائم ينشئ نسخة بيانات مشفرة عند 00:00 UTC ويستدعي الخدمات الخلفية الأخرى بمواعيدها القائمة. نسخة `.ksab` الحالية AES-GCM بمفتاح `BACKUP_ENCRYPTION_KEY` مستقل، لا `AUTH_SECRET`. مفتاح التدوير السابق اختياري؛ لا تُصدر قيم أسرار Worker عبر API، وتبقى عهدتها منفصلة عن النسخة.

نسخة التطبيق تتضمن البيانات والمخطط ومراجع الوسائط، وتستثني رموز وجلسات المصادقة. ليست نسخة بايتات الوسائط كلها ولا مخزناً مفصول الصلاحيات. التصدير المنقح يطبق سياق الإزالة الحديث وtombstones، ويحافظ على المواقع المحتفظة والمراجع الضرورية دون إتاحة دخول أصحاب الحسابات المحذوفة. تنزيل النص المنقح يختلف عن تنزيل الملف المشفر الخام: الأخير يحتفظ بمحتواه التاريخي ويحتاج تطبيق سياق الإزالة عند الاستعادة. فحص التشفير واكتمال الوسائط ونجاح الاستعادة ثلاث نتائج منفصلة.

CP0 للمواءمة التقطت قبل أول تغيير: المصدر وتاريخ Git وحزمة العامل وإعداداته و70 جدولاً شاملاً المصادقة داخل تشفير فقط و55 كائن R2 ببايتاتها و82 أصلاً منشوراً. فُك كل ظرف وتحققت البصمات، وثبت ثبات D1/R2/Worker أثناء الالتقاط. هذه نقطة موجهة لرجوع المنصة نفسها وليست لقطة ذرية عالمية أو تمريناً ناجحاً لإعادة تشغيل الإنتاج. إضافة beacon التي يحقنها Cloudflare في offline.html محفوظة دون تعطيلها؛ القالب المحلي محفوظ كذلك. كل هذه القطع والمفتاح خارج Git، ولا يرفقان افتراضياً.

قبل أي رجوع: توقف عند سبب محدد، احفظ البيانات والتحرير الأحدث، وقرر بين إعادة نشر شيفرة متوافقة وتصحيح أمامي. لا يسترجع العامل وحده بيانات D1/R2، ولا تنسخ بيانات قديمة فوق الحديثة لإجبار التطابق.

## الاستعادة المعزولة الحالية

الأداة القائمة تقبل نسخة v2 فقط وسياق إزالة أحدث من النسخة، وتكتب SQLite جديداً لا ملفاً موجوداً ولا قاعدة الإنتاج:

```bash
# تُحمّل قيمة المفتاح من خزنة مخولة إلى البيئة، ولا تُكتب في Git أو سجل أو محادثة.
python3 scripts/restore_snapshot.py snapshot.ksab restored.sqlite \
  --sha256 "البصمة_المرفقة_بالنسخة" \
  --tombstones current-erasure-context.json
```

يجب وجود `BACKUP_ENCRYPTION_KEY` أو `BACKUP_RECOVERY_KEY_HEX` في البيئة المخولة. `AUTH_SECRET` غير مقبول لهذه الأداة ولا يُستعمل بديلاً. سياق الإزالة من المسار المحمي `/api/admin/backup-erasure-context` بجلسة المالك والتحقق الحديث. لا تُحفظ استجابة هذا المسار في Git أو تقرير عام.

الأداة لا تستعيد الجلسات أو رموز الدعوة، وتثبت المشغلات بعد استيراد البيانات حتى لا تعيد منح نقاط أو تكرر إجراءات تاريخية. نتيجة SQLite integrity والمفاتيح الخارجية ليست برهان تشغيل الوسائط أو التعافي السحابي؛ يعالج تمرين ج الأساسية هذه الحدود لاحقاً. لا تبدأ الأداة باستعادة إنتاجية ولا توسع حصانات الاحتفاظ.

## التعامل مع فشل مرحلة

إن فشل حفظ R2 أو التزام D1 لمهمة تجهيز، لا يعرض المنتج «جاهزاً» قبل تحقق التخزين والالتزام. يظل أثر المتابعة قابلاً للاستئناف المحدود، ولا يعاد بريد sent/uncertain أو بريد تاريخي مجهول الجسم تلقائياً. الحذف blocked ليس نجاحاً، وإخفاء الموقع ليس إتلافاً. بقاء السجل المالي والتدقيقي أو علاقة مرجعية يحتاج تصنيفاً وسنداً ومسؤولاً ومدة، ولا يصلح ذريعة مفتوحة لحفظ الملف كله.

القبول الحي بعد النشر قرائي واحد: إصدار ونسبة مرور ومهاجرات ومسارات وحراس وبيانات الحفظ. أي اختلاف متزامن يُفسر ولا يُرد تلقائياً. القبول البشري من الجوال مسؤولية المالك أو ممثله، ولا تنسب اختبارات DOM أو حجم شاشة افتراضي إلى أجهزة حقيقية أو شهادة إتاحة.

## النقل والاستنساخ والحدود

الحزمة الرديفة والموارد الأخرى خارج نطاق المواءمة. أداة `scripts/package_transfer.py` تنتج مصادر منقحة، ولا تنقل حسابات الأصل أو أسراره. النسخة المستقلة تحتاج مواردها وعهدتها وإفصاحاتها، ولا تطبق مهاجراتها المعدلة على الأصل.

هذه إجراءات تقنية لا ادعاء امتثال كامل أو أمان مطلق أو محو مادي أو استعادة إنتاجية لم تحدث. النتائج التاريخية في `ACCEPTANCE.md` ووثائق النشرات السابقة تُقرأ مع تاريخها؛ لا تستعمل قبولاً بديلاً عن نتيجة هذه المواءمة.
