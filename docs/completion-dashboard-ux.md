# إكمال تجربة لوحة التحكم: التنبيهات والرسائل والترجمة

**نطاق هذه الدفعة:** `client/src/Dashboard.tsx` و`client/src/dashboard.css` وهذا المستند فقط. لا تتضمن الدفعة كتابة إنتاجية أو نشرًا أو تعديلًا لمسارات الخادم أو ملفات القفل.

## السلوك المنفذ

| المتطلب | التنفيذ في الواجهة | الحد الصريح |
|---|---|---|
| صوت تنبيه اختياري ومحلي | إعداد «صوت التنبيهات» في الإعدادات متوقف افتراضيًا، ويحفظ الاختيار في `localStorage` لهذا المتصفح فقط. التفعيل ينشئ/يستأنف `AudioContext` أثناء تفاعل المستخدم نفسه، ثم تصدر نغمة قصيرة للتنبيهات الجديدة فقط. | لا يرسل التفضيل إلى الخادم، ولا تحاول الواجهة تشغيل الصوت قبل تفاعل المستخدم. |
| تحديث التنبيهات | يبدأ مؤقت 30,000ms عند ظهور المستند فقط ويتوقف عند إخفائه، ويستأنف التحديث عند العودة للواجهة. يجلب `GET /api/dashboard` ويَدمج حقل `notifications` وحده. | لا يستبدل هذا التحديث المسودة أو الموقع النشط أو أي بيانات تحرير محلية. أول حمولة تسجل المعرّفات ولا تصدر صوتًا؛ الصوت للنصوص التي تُرى جديدة بعد ذلك فقط. |
| احتفاظ الرسائل وانتهاء المحادثة | تعرض لوحة الرسائل فترات `messagesDays` و`reportDays` و`authDays` التي يعيدها `GET /api/messages` إن كانت صالحة للعرض. تلتقط الواجهة استجابة `410` من `GET /api/conversations/:id` وتعرض حالة منتهية بلا سجل رسائل وبلا حقل إرسال. | انتهاء المحادثة أو عدم إتاحة سجلها لا يساوي وعدًا بحذف أو تطهير فوري للبيانات. تظل الرموز الإيجابية العشرة المختارة كما هي في جلسات المراسلة النشطة. |
| الترجمة المحفوظة | واجهة اتجاه صريحة: العربية → الإنجليزية أو الإنجليزية → العربية. يرسل الطلب إلى `POST /api/translate` مع `siteId` و`target: 'ar' | 'en'` و`consent: true` فقط بعد الموافقة. لا يظهر محرر الهدف إلا إذا أعاد الخادم النسخة المحفوظة لذلك الهدف. | تدمج الواجهة **نسخة الهدف التي أعادها الخادم فقط** وتحافظ على محرر المسودة العربية الرئيسي وأي تعديلات محلية غير محفوظة؛ لا تنشئ نصًا مترجمًا في العميل ولا تستبدل المصدر. |
| التصدير الإنجليزي | اختيار التصدير الإنجليزي معطّل حتى توجد `draft.translations.en` المخزنة؛ لا تُنشأ روابط تصدير إنجليزية قبل ذلك. | لا تعتمد إتاحة التصدير على نص مترجم شكلي أو قيمة افتراضية محلية. |
| رؤى الموقع المفوض | يرسل طلب الجودة إلى `GET /api/analytics?siteId=<activeSite.id>`، حيث يطبق الخادم تفويض الموقع القابل للتحرير. | لا تنسب الواجهة قياسات موقع إلى موقع آخر. |

## عقود التكامل التي تعتمد عليها الواجهة

1. `GET /api/dashboard` يعيد `notifications` ضمن لوحة المستخدم.
2. `GET /api/messages` يعيد `requests` و`conversations` و`blocks` وتهيئة `retention` الخادمية. الإعداد الافتراضي المحلي الحالي يتضمن 30 يومًا للرسائل، و180 يومًا لأدلة البلاغات، و7 أيام لبيانات التحقق، لكن الواجهة تعرض ما يعيده الخادم فعليًا فقط.
3. `GET /api/conversations/:id` يعيد `410` عندما تصبح المحادثة منتهية ولا يعود سجل الرسائل متاحًا.
4. `POST /api/translate` يقبل اتجاه الهدف `ar` أو `en` وموافقة حرفية `true`، ويجب أن يعيد المسودة ذات الترجمة المحفوظة للهدف المطلوب كي تعتبر الواجهة العملية ناجحة.
5. `GET /api/analytics?siteId=<uuid>` يحمي الوصول الخادمي للموقع القابل للتحرير.

## التحقق

- نجح `git diff --check` على الملفات الثلاثة المصرح بها بعد التعديلات.
- نجح `pnpm exec vite build` محليًا في 2026-10-27؛ التحذير الوحيد المعروف هو حجم حزمة PDF المتجاوز 500kB، وليس خطأ بناء.
- نجح فحص TypeScript الصارم والمركز على `client/src/Dashboard.tsx` مع اعتماداته العميلية (`pnpm exec tsc --noEmit ... client/src/Dashboard.tsx`).

## مخاطر تكامل متبقية

- تشغيل الصوت قد يرفضه متصفح أو سياسة تشغيل تلقائي؛ عند ذلك يبقى الإعداد المحلي متوقفًا وتستمر التنبيهات المرئية بلا تعطيل.
- يلزم اختبار مسجل دخول للتحقق النهائي من مسارات الخادم، خصوصًا استجابة 410، إعدادات الاحتفاظ الفعلية، وحفظ الاتجاهين بعد الموافقة. لا يوجد في هذه الدفعة اختبار شبكة خارجية أو كتابة إنتاجية.
- يجب أن يظل مسار الخادم المتفق عليه `/api/translate` متاحًا؛ لا تستخدم الواجهة مسار ترجمة بديلًا ولا تفترض نجاحًا إذا لم تستلم نسخة الهدف المخزنة.
