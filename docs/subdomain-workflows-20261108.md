# رابط الهوية وروابط المشرف — 8 نوفمبر 2026

## التنفيذ

أسفل رابط الهوية في لوحة المستخدم زر تعديل وزر طلب نشر. طلب النشر دون تعديل اسم يمر عبر مسار النشر المعتاد؛ تعديل الاسم يحفظ النص الحالي أولاً، ثم يرسل مراجعة وهوية بالمعرف وصاحب الحساب نفسيهما. يقبل اسماً مختصراً أو النطاق الكامل مثل VIP.KSA.MEN ويطبّع الحروف إلى صغيرة. يبقى الاسم الحالي فعالاً حتى الاعتماد، ويصبح الاسم السابق متاحاً للغير بعده. تعرض الواجهة هذا الأثر قبل الطلب ويعرضه المشرف في بطاقة المراجعة. لا ينشأ alias أو تحويل من الاسم السابق؛ لذا الروابط والبطاقات القديمة تحتاج تحديثاً بعد تغيير الاسم.

أضيف0019 بجداول طلبات الاسم وروابط المشرف وفهارس جزئية ومحفزات فقط، دون DELETE أو DROP أو تعديل ترحيل سابق. حجز الاسم المعلق منفصل ومحمي في مستوى D1 لكل إنشاء/تحديث dns_names وحجز سياسة. تغيير name في الصف نفسه ضمن قرار review_decisions يربط النشر وتحرير القديم في معاملة واحدة. الطلب الأحدث لا ينفذ على مراجعة أقدم من رقم نسخته. الرفض أو الاستبدال أو الإلغاء يحفظ التاريخ ويحرر الحجز المعلق دون تغيير الاسم الحالي. اعتماد نسخة أحدث من المسودة عبر زر بطاقة المستخدم يحمل طلب الاسم المعلق. إشعارات النشر الحالية تستخرج الرابط الجديد بعد الالتزام، وتكرار القرار لا يغير ملكية أو محتوى أو دفاتر.

«روابط التحويل» تبويب خاص بالمشرف الرئيسي فقط. يقبل رابطاً كاملاً ووجهةHTTPS ويتيح حجزاً وتفعيلًا بضغط واحد، وتعديل الوجهة وإيقاف التحويل. الحجز في dns_names نفسه؛ لا يستولي على اسم عضو أو حجز تقني أو طلب معلق. الإيقاف يحتفظ بحجز الاسم. تحويل302 بلا تخزين وبلا تمرير معلمات الزائر، لزيارة الجذر فقط وليس API أو ملفات. تمنع بيانات الاعتماد والوجهات المحلية والحلقات برمجياً وفي D1 تحت التزامن، ويحترم قفل المنصة. لا توجيه أعضاء ولا تنازل أسماء أو تغيير مالك.

## الحفظ والتحقق
