# إعادة تصميم الهوية الشخصية — 28 أكتوبر 2026

## النتيجة

أُعيد بناء صفحة الهوية العامة في `client/src/Personal.tsx` كصفحة تحريرية سعودية مستقلة بصريًا تحت هوية KSA.MEN. يعتمد التصميم على غلاف المنشور وصورة الحساب الفعليين فقط، مع استخدام غلاف KSA.MEN أو أيقونته عند غياب الوسيط. لا ينشئ التصميم أشخاصًا أو إنجازات أو مؤهلات بديلة.

الصفحة قصيرة وواضحة عند البداية: غلاف بانورامي، صورة الهوية، الاسم والمسمى والموقع الجغرافي، وعنوان `<bdi dir="ltr">name.ksa.men</bdi>`، ثم زرا حفظ جهة الاتصال والمشاركة. على سطح المكتب توجد بطاقة هوية وتواصل ثابتة بجانب المسيرة؛ وعلى الجوال تظهر المقدمة أولًا ثم أقسام المسيرة والقدرات والشواهد كاملة دون شريط أقسام أفقي أو مساحة فارغة طويلة.

## ما بقي محفوظًا

- طلب الملف العام: `GET /api/public/profile?lang=...`، وحالة التحميل، الخطأ، وقفل الموقع بكلمة المرور عبر `POST /api/public/unlock`.
- تسجيل القياسات العامة الموجودة فقط: `visit` بعد تحميل موقع متاح، و`contact` و`vcard` و`qr` عند الإجراء المقابل عبر `POST /api/public/event`.
- حفظ بطاقة vCard باستخدام `generateVCard` من `Exports.tsx`، ومشاركة الرابط عبر Web Share أو النسخ للحافظة، وإنشاء QR بعلامة الصورة المتاحة.
- جميع الحقول والقوائم المنشورة: الاسم، المسمى، النبذة، المدينة/الدولة، الخبرات، التعليم، التدريب، المهارات، العضويات، اللغات، الاهتمامات، الإنجازات، السجل الزمني، صور إثبات المهارة، نماذج الأعمال، فيديو YouTube، البريد والهاتف وWhatsApp، الروابط الاجتماعية، الأزرار المخصصة، و`allowContact` و`branding`.
- خصوصية الزائر والمالك: لا تحاول الواجهة استرداد الحقول المحجوبة أو تجاوز تصفية `visibleProfile` الخادمية؛ وتعرض فقط ما أعاده API العام. تظهر وصلة «طلب تواصل مهني» فقط عند `allowContact !== false` ومعرّف مستفيد متاح.
- صور الشواهد تستخدم `<dialog>` أصليًا (`showModal`) مع Escape، backdrop، زر إغلاق، وإغلاق عند الضغط خارج الإطار؛ وبالتالي تحصل على إدارة التركيز الأصلية للمتصفح.

## التوافق البصري والتنفيذي

`personal.css` محصور ضمن `.identity-page` أو فئة حوار محددة. يستخدم رموز Parent العالمية (`--bg`, `--surface`, `--surface-2`, `--text`, `--muted`, `--border`, `--accent`, `--green`) مع fallback لـ `--gold`، ولا يغير `:root` أو `body` أو مكونات الصفحات الأخرى. يتضمن نقاط توقف عند 1200 و960 و640، دعم `prefers-reduced-motion`، وتخطيط طباعة يحذف إجراءات الواجهة وبطاقة التواصل.

لا يتطلب التكامل تعديلًا في المسار: `main.tsx` يستورد `Personal` lazy بالفعل ويحمّل `style.css` قبل stylesheet الخاص بالمكون. أبقِ استيراد `./personal.css` داخل `Personal.tsx` كما هو، ولا يلزم أي أصل جديد أو تغيير API أو قاعدة بيانات أو CSP.

## ملاحظات مراجعة Parent

- ملف `style.css` الحالي ما زال يحتوي على محددات شخصية قديمة، لكن أسماء التصميم الجديد كلها تبدأ بـ `identity-` ولا تعتمد عليها؛ يمكن للـ Parent تنظيف تلك المحددات في تغييره المملوك إن أراد، دون أن يكون ذلك مطلوبًا لعمل الشاشة الجديدة.
- اختبار الفحص المطلوب بعد الدمج هو `pnpm typecheck` مرة واحدة. لا توجد اختبارات جديدة أو حزم إضافية.
