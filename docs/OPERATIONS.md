# تشغيل KSA.MEN

المنتج مستقل على Cloudflare Workers وD1 وR2 وWorkers AI وResend. لا توجد خدمة تشغيل Manus. المستودع wwwksamen-crypto/ksa.men. نسخة الجوال هي الأساس، مع العربية والإنجليزية والوضع الداكن والفاتح.

## الدخول والمالك

الدخول من /auth أو /admin بالبريد www.ksa.men@gmail.com. يرسل التطبيق رمزًا صالحًا لعشر دقائق ولمرة واحدة. أول تحقق لهذا البريد يربط صلاحية المالك في الخادم. يمكن بعدها اختيار PIN من6أرقام للجهاز الموثوق. الدخول بـPIN لا يعتبر تحققًا حديثًا للإجراءات الحساسة؛ يلزم تحقق بريد خلال15دقيقة. لا توجد كلمة مرور إدارة ثابتة أو مستخدم سري. الملف الخاص.dev.vars مستثنى منGit، وأسرار الإنتاج WorkersSecrets.

## البناء والنشر

`pnpm install --frozen-lockfile` ثم `pnpm typecheck` و`pnpm build`. تنفيذ`pnpm run deploy` ينشرWorker الخاص بالمشروع فقط. متغيرCLOUDFLARE_API_TOKEN متاحللمشرفالمصرحومحددللحساب. لايُحفظفيالمستودع. secrets RESEND_API_KEY وAUTH_SECRET يجبنقلهمابأوامرWorkersSecrets دونطباعتهما. مواردD1/R2سماءثابتةداخلwrangler.jsonc. ترحيلاتSQL إضافةوتحديثفقط،وتطبقRESTscript معSHA256لكلنسخة. لاDELETE/DROPأوتغييرفوترة.

## الحفظ والاستعادة

حفظGitcommit لكلانتقالبنسخةصدريةودليلSHA256؛نسخةقبلاستهدافDNSوالـroutesوالـWorkersettings/deploymentsمحفوظةخارجمجلدالمستودعالعام. قبلنشرأيإصلاحلاحقفاحفظالإصدارالنشطوالنسخالمخصصة؛لايمكنمعاملةهذهالنقطةكحذفبيانات. rollbackواجهة/خادم: أعِدنشرإصدارGitالذيكانناجحًاإلىنفسWorkerبدونتغييرD1 أوR2؛مهاجراتجديدةيجبأن تبقىمتوافقةمعالإصدارالسابق. rollbackدومين:استعادةسجلالهدفالمحفوظبتحديثمحدد،لاتلمسDNSالبريد. توجدنسخةJSONمنالإدارةمحميّةللمالكبعدتحققحديث؛ النسختشملالأدلةوالسجلاتلاالأسرارولاهاشPINأورموزالجلسات. وسائطR2تحتاجنسخبِطريقتِهامنفصلة؛JSONليسنسخةكاملةلكلملفاتR2.

النسخالأوليتمحفظهقبلالنشر. النسخ الليلي لقاعدة البيانات فعال عند00:00UTC (03:00السعودية)، مشفرAES-GCM داخلR2 للمشروع، معSHA256 وحقول التحقق. هذه النسخة داخل حسابCloudflare ذاته وليست نسخة خارجية مستقلة؛ ملفات الوسائط الأصلية غير قابلة للتعديل وتحتفظ بهاR2 بأسماء فريدة. لا يوجد حذف آلي لنسخ قديمة ضمن صلاحية التنفيذ الحالية. الرادار يعملCronكل6ساعاتداخلWorkersولايعتمدعلىجلسةManus،وذلكللجلبالحاليالمصرحمنمصادرRSSالمتاحة.
