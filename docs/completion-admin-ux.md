# تحسين تجربة إدارة الخدمات والمراجعات

**النطاق المنفذ:** `client/src/Admin.tsx` و`client/src/admin.css` وهذه المذكرة فقط. لم تُعدّل أي ملفات خادم أو بيانات إنتاج أو أقفال، ولم تُنفذ استدعاءات خارجية أو نشر أو عمليات Git.

## إدارة سياسات الخدمات

- تستبدل تبويبة **الخدمات والاستحقاقات** عرض JSON الخام بمحرر واضح يظهر للمالك فقط.
- لكل خدمة، تظهر مصادر الاستحقاق الأربعة كخانات اختيار قابلة للوصول: **التجربة / Trial**، **الاشتراك / Subscription**، **المنح الإداري / Administrative grant**، و**النقاط / Points**.
- تبدأ كل خانة من السياسة التي أعادها الكتالوج. تكون القيمة غير الموجودة مفعّلة، بما يتفق مع تقييم الاستحقاق في المنصة، وتبقى أي خصائص سياسة أخرى غير معروضة محفوظة عند التعديل.
- يحفظ زر صريح سياسة الخدمة عبر `PUT /api/admin/services/:key` بحمولة تشمل دائماً حالة الخدمة المحمّلة `enabled` وكائن `policy` كاملاً. تُنتظر الاستجابة، ثم يعاد تحميل قائمة الإدارة. أخطاء الحفظ تبقى في تنبيه الإدارة ذي الدور `alert`.
- يظل تعليق أو إعادة تفعيل الخدمة العامة للمالك فقط، ويرسل أيضاً السياسة الحالية حتى لا يفقد التحديث أي إعدادات سياسة. يستطيع المدير الاطلاع على حالة الخدمات العامة ضمن نطاقه، من دون ظهور عناصر تحرير السياسة.

## معاينة المراجعات

تستخدم بطاقة المراجعة رابط `preview_url` المعاد من القائمة، مع المسار الفعلي `/api/admin/reviews/:id/preview` كبديل مرتبط بمعرّف المراجعة. أصبح النص يوجّه المراجع ببساطة إلى فتح معاينة الموقع عند الحاجة قبل اتخاذ القرار، بدلاً من إظهار تنبيهات تقنية عن غياب المعاينة.

## التحقق

- استُخدم عقد مسار الخدمات لالتزام وجود `enabled` البولياني في كل طلب تحديث.
- لم يُشغّل أي اختبار يتطلب جلسة إدارية أو يكتب إلى موارد بعيدة.
- نجح `pnpm typecheck` بلا أخطاء TypeScript.
- نجح `pnpm exec vite build --outDir /tmp/ksa-men-vite-admin-check --emptyOutDir`. اقتصر التحذير على حجم حزمة PDF القائمة ولم يمنع البناء.
