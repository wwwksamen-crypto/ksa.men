# تشغيل KSA.MEN واستعادته

المنتج مستقل على Cloudflare Workers وD1 وR2 وWorkers AI وResend، ومستودعه تحت حساب المالك: `wwwksamen-crypto/ksa.men`. لا توجد استضافة تشغيل Manus أو دومين اختبار منفصل. العربية ونسخة الجوال أساس التصميم، مع الإنجليزية والمظهرين.

## الدخول والإدارة

الدخول من `/auth` أو `/admin` ببريد المالك المحدد في `OWNER_EMAIL`. يرسل التطبيق رمزًا لعشر دقائق ولمرة واحدة. يمكن اختيار PIN من ستة أرقام بعد توثيق الجهاز. دخول PIN لا يُعد تحققًا حديثًا للإجراءات الحساسة؛ تلك الإجراءات تحتاج تحقق بريد خلال 15 دقيقة. لا توجد كلمة مرور إدارة ثابتة أو مستخدم سري. تُحفظ أسرار الإنتاج في Workers Secrets، وتُستثنى `.dev.vars` من Git.

تبقى قيمة قفل المالك دون تغيير في الإصدار الحالي. لا تُفتح الرئيسية أو المنصة نتيجة ترحيلة أو نشر. معاني أوضاع القفل وصلاحيات المرور تُطبق من الخادم، ولا يتجاوزها كاش PWA.

## البناء والنشر

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm run deploy
```

موارد الإنتاج مرتبطة في `wrangler.jsonc`. متغير النشر `CLOUDFLARE_API_TOKEN` خارج المستودع ومقيد بالحساب المصرح. تستخدم الشيفرة `AUTH_SECRET` و`RESEND_API_KEY` في Workers Secrets دون إظهار القيم. لا تستخدم رمز نشر Cloudflare داخل التطبيق.

تحفظ أداة `scripts/production.py checkpoint` إعدادات النشر قبل الانتقال، وتطبق `migrate` ترحيلات إضافية مسجلة ببصماتها. لا تعدل ملف ترحيلة مطبقة، ولا تنفذ DELETE أو DROP أو عملية فوترة أو تغييرًا عامًا على DNS البريد.

## النسخ والاستعادة

ينفذ Cron الرادار كل ست ساعات، وينشئ عند 00:00 UTC (03:00 السعودية) نسخة بيانات AES-GCM في R2 الخاص بالمشروع. يمكن للمالك إنشاء نسخة والتحقق منها وتنزيل ملف مشفر بعد تحقق حديث. التنزيل الإداري العادي لا يكشف هاش PIN أو جلسات أو الرسائل الخاصة أو أدلة البلاغات.

النسخة المشفرة تضم مخطط البيانات والجداول التشغيلية ومراجع الوسائط. ملفات الوسائط الأصلية غير قابلة للاستبدال وتظل في R2؛ الملف المشفر ليس أرشيفًا لبِتّات كل الوسائط، ولا نسخة مستقلة في حساب آخر. لا يوجد حذف آلي للنسخ القديمة ضمن الصلاحية الحالية.

للاستعادة إلى ملف SQLite جديد، وليس إلى الإنتاج:

```bash
# ضع المفتاح المشتق في خزنة آمنة، ولا تحفظه في Git.
export BACKUP_RECOVERY_KEY_HEX="قيمة_من_ملف_الاستعادة_السري"
python3 scripts/restore_snapshot.py snapshot.ksab restored.sqlite --sha256 "البصمة_المرفقة_بالنسخة"
```

يمكن بديلًا استخدام AUTH_SECRET في البيئة القديمة. المفتاح المشتق الخاص بالنسخ لا يكشف سر مصادقة التطبيق. ترفض الأداة استبدال ملف موجود وتتحقق من checksum وSQLite integrity والمفاتيح الخارجية. لا تستعيد جلسات المصادقة، ولا تعيد منح مكافآت التسجيل أو تشغيل مشغلاتها على البيانات التاريخية.

نجحت الاستعادة الفعلية للنقطة النهائية إلى ملف جديد باستخدام المفتاح المشتق، دون تعديل الإنتاج. إعادة تفعيل إنتاج مستعاد تحتاج خطة نقل توافقية تحافظ على البيانات الأحدث؛ ليست ضغط زر يمحو D1.

للرجوع في الشيفرة، أعد نشر commit ناجح إلى Worker نفسه، دون تغيير بيانات D1 أو R2. إذا استلزم الأمر ربط الدومين، حدث سجل الهدف المحدد من النقطة المحفوظة فقط، دون مساس بسجلات البريد أو مشاريع أخرى.

## النقل والاستنساخ

تنتج `scripts/package_transfer.py` حزمة مصادر خالية من الأسرار والجلسات وقاعدة المستخدمين. خيار `--clone` يستبدل الدومين والبريد والاسم، ويحذف وثائق الشركة وبيانات الحوالة ومعرفات حساب الإنتاج. يلزم للنسخة المستقلة حسابها وقاعدتها وتخزينها وأسرارها وهوية ووثائق صاحبها. تبقى الحوالات معطلة حتى تزويدها بمستفيد رسمي. لا تطبق ترحيلات استنساخ معدلة على قاعدة الأصل.

## التدقيق والتسليم

اكتملت الجولة البرمجية النهائية 37/37، و27 تحققًا إنتاجيًا مميزًا، وجولات متصفح للمالك والمدير والمشرف والعضو على الدومين الحقيقي. نُزّلت ملفات PDF وATS العربية والإنجليزية وVCF وPNG من الواجهة، وعُولجت الملاحظات البصرية ثم أُعيد التحقق. التفاصيل في `ACCEPTANCE.md`.

حساب التدقيق موسوم ومعلّق، وموقعه ظل مقفلًا. لا توجد بيانات أعضاء بشرية وهمية أو حوالات مصرفية مدعاة. لا تُنسب هذه الجولة إلى قبول بشري؛ ذلك قرار المالك اللاحق على النسخة المقفلة.

لا توجد ضمانات منع تصوير الشاشة، أو قبول كل ATS، أو توظيف، أو أمان مطلق. تظهر حدود المورد أو تعذر RSS أو حصة الترجمة كما هي. مدد الاحتفاظ المعروضة ليست ادعاء حذف مادي لم يُنفذ. لا تُعرض رسوم مزود أو استهلاكه اللحظي على أنهما مقاسان إن لم يتوفر مصدرهما.
