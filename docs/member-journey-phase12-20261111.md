# تبسيط رحلة العضو — المرحلتان الأولى والثانية

## النطاق والعقد

التنفيذ فوق المنصة الحالية دون إعادة بناء أو وكلاء أو تغيير محركات الحفظ والرفع والحجز والنشر والصلاحيات. المرحلة الأولى تثبيت الواقع والاحتفاظ، والثانية تبسيط رحلة العضو فقط. تبقى إعادة تنظيم الإدارة والحذف وسند والمحاذاة العامة والإصدار الموحد مراحل لاحقة. المصدر محفوظ محلياً ثم في GitHub بعد الحراسات؛ لا نشر Worker في هذه الدفعة.

المعاينة الأولية في My Browser كانت قرائية: ظهرت جلسة المالك وتنظيم المتابعة والتشغيل والحوكمة والنظرة التنفيذية؛ لم يستخدم زر إدارة أو نشر أو حذف. لوحة العضو ظهرت أثناء التحميل، وتعثر أحد استدعاءات القراءة بالمهلة؛ لا يدّعى اكتمال معاينة عضو محملة أو تشخيص سبب غير مثبت. لا جولات متصفح للواجهة الجديدة أو بيانات إنتاجية تجريبية؛ قبولها الحي للإصدار الموحد.

| النطاق | الواقع والتغيير |
| --- | --- |
| الحجز | عنوان الموقع كاملاً وتوافره، ثم نفس /api/names/reserve الذي ينشئ المسودة فعلاً. ليس حجزاً وهمياً في الواجهة. |
| التعريف | الاسم والمسمى والتخصص والمدينة ونبذة، والصورة والغلاف تحت خيار إضافي. المسمى وبقية الأقسام اقتراحات لا شروط نشر جديدة؛ publicationProfile يستعمل اسم الحساب عند ترك الاسم فارغاً. |
| المراجعة | حفظ أحدث تعديل قبل معاينة IdentityView الحقيقية، ثم نفس submitForReview ومسار /api/sites/:id/submit. لا نجاح أو نشر عام قبل استجابة الخادم واعتماد المخول. فشل الحفظ يبقي العمل ويمنع تقدم المعاينة؛ فشل الإرسال لا يغير الحالة إلى منشور. |
| التنقل | موقعي، مخرجاتي، حسابي. الإعدادات والعضوية والنقاط والإحالات والألعاب والرسائل باقية داخل حسابي؛ التصديرات والخدمات والترجمة باقية داخل مخرجاتي. |
| العضو الحالي | ملخص الموقع وأفعال تعديل ومعاينة وطلب نشر، ثم المحرر الكامل بقسم مختار واحد وقائمة خمس مجموعات قابلة للطي. تعديل العنوان موجود داخل خيار فرعي، ولا يتغير تدفق اعتماده أو تحرير الاسم السابق. |
| المخرجات | روابط التصدير الفعلية أولاً، قبل أدوات الجودة والترجمة، بمصادر المسودة المصادق عليها والاستحقاقات القائمة بلا تعديل مولد PDF/ATS/QR/vCard أو الشعار أو الخصوصية. |
| التوافق | تبويبات tab السابقة وsite للإسناد باقية، وmode=edit يفتح المحرر الصريح. تبديل المواقع يفرغ الحفظ المتزامن قبل فتح الموقع الجديد كما كان. |

## ما لا يتغير

لا تعديل لمسارات الخادم أو SQL أو الترحيلات أو DNS أو الأسرار أو القفل أو الأسعار أو الحسابات. محتوى المستخدم لا يصحح قسراً ولا يستبدل ببيانات توضيحية. الحفظ عبر version/revision والرفع الجماعي وأربع صور الإثبات والنماذج والإملاء وخصوصية الأقسام والصور وIdentityView نفسها تبقى قائمة.

تعريف الإزالة من الموجود: إزالة الهوية التشغيلية مع مراجع دنيا وسجلات مالية/تدقيقية محتفظة وحصانات وطابور وسائط؛ لا ادعاء مسح كل أثر من كل نسخة أو تنفيذ حذف إنتاجي. الأحداث المهمة ذات الأثر تسجل، لا كل حرف أو حركة. هذا تعريف عقد المرحلة الأولى لا تطوير للحذف.

## المسؤوليات والأدلة

`member-journey.ts` خرائط عرض وتوافق فقط. `MemberSiteJourney.tsx` مكونات مراحل وتعريف مختصر وملخص تستخدم DictatedInput/DictatedTextarea الحاليين. `member-journey.css` معزول للوحة والمراجعة، لا CSS عام أو هوية عامة أو PDF. `Dashboard.tsx` يحتفظ بمحركات الحفظ والنشر والرفع والخصوصية القائمة. `tests/member-journey.test.tsx` حراسات محلية؛ اختبار سباقات المحرر يبقى على وضع التحرير الصريح مع إزالة اختبار زر سفلي حذفت ازدواجيته فعلاً، دون إلغاء حراسات السباق والحفظ والرفع.

نقطة الاستعادة مستقلة ومشفرة قبل المصدر، ومرجع المصدر الأول محفوظ. runtime/post-edit غير متاح بسبب مستودع خارجي بلا مشروع نشط؛ لا إعادة تهيئة، وتستخدم الأنواع والفحوص المحلية المتصلة. تلحق نتائجها الفعلية بعد اكتمالها، ولا تعد صورة My Browser للنسخة القديمة قبولاً للنسخة الجديدة.

## نتيجة الفحص المحلي

نجح TypeScript و64اختباراً في9ملفات متصلة، والبناء وWrangler dry-run بلا نشر. نجحت رحلة الحجز والتعريف الاختياري والمراجعة بالمسار القائم، حفظ أحدث تعديل قبل الإرسال، الإخفاق دون نجاح وهمي، ثبات حقل الكتابة عبر الحفظ، وبقاء الصور والخصوصية والإملاء وتبديل المواقع والروابط القديمة. لا قبول حي للواجهة الجديدة؛ معاينة العضو القديمة غير مكتملة، ومعاينة المشرف قرائية فقط، فلا يغلق الشرط البصري. ملفات الخادم والترحيلات والمصادقة ومولدات المخرجات والأصول والإعدادات المالية لم تتغير.
